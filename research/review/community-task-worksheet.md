## Explain the project plainly

“We are testing whether a computer model can understand everyday written Tibetan and explain a supplied passage faithfully. We have not established that it can give reliable personal health advice. We want to learn which task is useful to test first and how people would judge a good answer.”

Use a speaker-reviewed explanation in the participant's preferred language. Do not assume the wording above is a reviewed Tibetan script.

## Learn about a concrete task

- Describe a recent or typical situation in general terms, without personal identifiers:
- What information did someone need?
- How would they obtain it today? What works or fails?
- What language, reading level and writing style would make it understandable?
- What would a successful answer let someone understand or do?
- Which mistakes would make the answer misleading or unusable?
- Would showing the original passage and its source help? Why?
- Would the task still be useful when the system can only explain supplied information?
- What should the system say when the passage does not contain the answer?
- What would make someone choose a person or another resource instead?
